1. ### **Ringkasan Eksekutif**

Untuk menghadirkan solusi yang praktis, efisien, dan ramah anggaran, Luvion Software menawarkan opsi **Pengembangan E-Katalog Digital OMEGA TOYS**. Opsi ini dirancang khusus bagi OMEGA TOYS untuk menampilkan seluruh koleksi mainan secara profesional, menarik, dan efisien di perangkat mobile maupun desktop tanpa rumitnya alur pembayaran otomatis.

Sistem ini berfokus pada kemudahan pameran produk (Showcase) serta percepatan konversi penjualan melalui integrasi tombol **Order via WhatsApp**. Pembeli dapat memilih variasi mainan, memasukkan ke keranjang belanja sederhana, dan langsung meneruskan detail daftar pesanan secara otomatis ke nomor WhatsApp Admin OMEGA TOYS..

Luvion Software hadir sebagai mitra teknologi strategis untuk merancang, membangun, dan mengimplementasikan solusi ini. Melalui proposal ini, kami menawarkan ekosistem aplikasi e-catalog yang dirancang spesifik sesuai dengan alur kerja operasional OMEGA TOYS.

2. ### **Keunggulan & Alur Kerja Sistem (WhatsApp Checkout)**

> 1. **Tampilan e-commerce-Style Sederhana:** Grid produk modern, bersih, dan sangat responsif saat dibuka dari HP pembeli.  
> 2. **Tanpa Biaya Transaksi Tambahan:** Karena tidak menggunakan payment gateway pihak ketiga, tidak ada potongan komisi per transaksi.  
> 3. **Pesan Otomatis ke WhatsApp:** Saat pembeli menekan tombol "Beli Sekarang", sistem secara otomatis menyusun format pesan rapi berisi daftar nama barang, varian, jumlah, dan perkiraan total harga langsung ke WhatsApp toko.  
> 4. **Mudah Dioperasikan:** Admin toko dapat menambah, mengubah harga, atau mengedit foto mainan kapan saja melalui Admin Panel sederhana.

### **3\. Cakupan Solusi & Fitur Utama Aplikasi**

### 

### **A. Sisi Pembeli (E-Katalog / Mobile-First)**

> 1. **Beranda & Banner Promo:** Banner slide promosi interaktif dan kategori mainan (misal: Mainan Edukasi, Figur, Mobil-mobilan, dll).  
> 2. **Pencarian & Filter Kategori:** Pencarian cepat produk berdasarkan nama dan pencarian filter kategori usia/jenis.  
> 3. **Halaman Detail Produk:** Galeri foto produk, harga, deskripsi lengkap, pilihan varian (warna/ukuran), dan status stok.  
> 4. **Keranjang Sederhana & Checkout WA:** Penampung daftar mainan yang dipilih sebelum dikirim langsung ke WhatsApp Admin.

### **B. Sisi Pengelola (Admin Panel)**

3. **Manajemen Produk & Kategori:** Tambah/edit/hapus produk mainan, atur harga promo/diskon, dan upload foto.  
4. **Pengaturan Nomor WhatsApp:** Kelola nomor WhatsApp tujuan penerima pesanan.  
5. **Pengaturan Banner Promosi:** Upload banner iklan/promo musiman di halaman utama.

### **4\. Arsitektur Teknologi & Keamanan**

Untuk mendukung operasi skala nasional yang andal dan aman, kami mengusulkan spesifikasi teknologi mutakhir dengan stabilitas tinggi:

| Komponen	Teknologi Pengembangan |  |
| :---- | :---- |
| **Backend Framework** | Laravel (Enterprise-ready PHP Framework) dengan performa tinggi & RESTful API Architecture. |
| **Frontend Interface** | Next.JS Tailwind CSS & Responsive Blade Components untuk antarmuka yang clean, cepat, dan mobile-first. |
| **Database System** | MySQL dengan pengindeksan data inventaris teroptimasi tinggi demi kecepatan query pencarian barang. |
| **Infrastruktur Server** | Direkomendasikan berbasis virtualisasi handal untuk manajemen resource komputasi yang fleksibel, didukung Cloudflare Tunnel demi keamanan jaringan tanpa IP publik terbuka. |
| **Sistem Keamanan** | Enkripsi SSL/TLS, proteksi berlapis dari serangan CSRF/XSS, serta Role-Based Access Control (RBacy) yang ketat untuk admin, operator gudang, dan klien.  |

**Ketentuan Fase Pengembangan (Development Phase):**  
Tujuan Penggunaan: Server ini disediakan secara terbatas hanya untuk kebutuhan pengujian fungsionalitas aplikasi selama proses pengembangan berlangsung.  
**Batasan Performa (Performance Limitation)**: Server tidak dirancang untuk menangani beban kerja berat (heavy workload), tidak mendukung fitur High Availability (HA), serta tidak menjamin stabilitas tinggi untuk akses pengguna massal (public users).

6. ### **Garansi, Pemeliharaan, & Dukungan**

**Garansi Sistem:** Dukungan penuh perbaikan bug atau error sistem secara gratis selama 1(Satu) bulan pertama setelah tanggal serah terima aplikasi (*Go-Live*).  
**Pemeliharaan Sistem Berkala (SLA Pasca-Garansi):** Setelah masa garansi habis, aplikasi wajib didaftarkan dalam program *maintenance* bulanan sebesar **Rp 100.000 / bulan**. Biaya ini mencakup:

* Monitoring stabilitas server harian dan optimasi database.  
* Backup data berkala secara rutin demi keamanan.  
* *Minor update* fungsionalitas agar sistem tetap relevan dengan perkembangan teknologi OS/browser.  
* Bebas biaya perbaikan jika terjadi kendala teknis operasional (*remote support*).

**Pengembangan Fitur Baru:** Permintaan modifikasi skala besar atau penambahan fitur baru di luar sistem yang sudah ada akan dikenakan biaya tambahan berbasis proyek (*by quotation*).

**Biaya Migrasi & Setup Server Baru:** Layanan pemeliharaan bulanan (*maintenance*) hanya berlaku pada server yang telah disepakati di awal (*existing server*). Jika Klien meminta pemindahan (migrasi) aplikasi dan database ke server/provider baru di kemudian hari, akan dikenakan biaya jasa konfigurasi dan migrasi sebesar **Rp 500.000 per proses migrasi** (tergantung pada ukuran data dan kompleksitas konfigurasi server baru).
